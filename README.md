# 포커 칩 계산기

맨 위 탭으로 두 모드를 바꿔 씁니다.

- **캐시 게임**: 바이인을 기록하고, 게임이 끝나면 남은 칩으로 누가 누구에게 얼마를 보내야 하는지 계산합니다.
- **토너먼트**: 정해 둔 시간마다 블라인드를 올려 주는 블라인드 타이머입니다.

**바로 쓰기:** https://pigfactory.github.io/poker-chip-calculator/

## 캐시 게임 사용법

1. 1바이인 금액과 1바이인 칩 수를 입력합니다 (예: 5,000원 / 500칩).
2. 인원을 추가하고 이름을 고칩니다. 바이인할 때마다 `+`, 잘못 눌렀으면 `−`.
3. **게임 종료**를 누르고 각자 남은 칩을 입력하면 정산 결과가 나옵니다.
4. **결과 복사**로 카톡 등에 붙여넣을 수 있습니다.

입력한 내용은 브라우저에 저장되어 새로고침해도 유지됩니다.

## 정산 규칙

- 송금 건수가 최소가 되도록 잃은 사람 → 딴 사람으로 짝지어 줍니다.
- 남은 칩 합계가 산 칩 합계와 다르면 가장 많이 딴 사람의 칩으로 차이를 맞춥니다.
  - 칩이 남으면 가장 많이 딴 사람 칩에서 뺍니다 (딴 만큼까지만, 넘치면 다음으로 많이 딴 사람).
  - 칩이 모자라면 가장 많이 딴 사람 칩에 더합니다.
  - 어떻게 보정했는지 결과 화면에 설명이 표시됩니다.

## 토너먼트 사용법

1. 시작 스몰·빅과 블라인드 업 간격(분)을 입력하고, 증가 방식을 고릅니다.
   - **같은 값 더하기**: 레벨마다 스몰·빅 증가값만큼 더합니다.
     예: 5/10 시작, +5/+10 → 5/10 → 10/20 → 15/30 …
   - **배수로 올리기**: 레벨마다 ×1.25(느리게) / ×1.33(보통) / ×1.5(빠르게) / ×2(터보)로 올립니다.
     실제 대회 구조표처럼 깔끔한 값(25·50·75·100·125·150·200…)으로 맞추고, 칩 단위(시작 스몰·빅의 최대공약수)로 나눠떨어지는 값만 씁니다.
     예: 25/50 시작, ×1.33 → 25/50 → 50/100 → 75/150 → 100/200 → 125/250 → 150/300 → 200/400 …
2. **미리 알림**에 몇 초 전에 알려줄지 입력합니다 (0이면 끔).
3. **시작**을 누릅니다. 아래 블라인드 스트럭처에서 앞으로 8레벨을 미리 볼 수 있습니다.

알림

- 미리 알림: 짧은 비프 두 번 + "30초 후에 블라인드가 올라갑니다. 다음은 스몰 10, 빅 20."
- 블라인드 업: 차임 + "블라인드가 올라갑니다. 레벨 2, 스몰 10, 빅 20." 화면도 깜빡입니다.
- 음성은 **음성 안내**로 끌 수 있고, **소리 테스트**로 볼륨을 미리 확인할 수 있습니다.

참고

- 타이머가 도는 동안 화면이 꺼지지 않게 유지합니다 (지원 브라우저).
- 새로고침하거나 화면이 꺼졌다 켜져도 시간이 맞게 이어집니다. 그 사이 지난 레벨은 한 번에 따라잡습니다.
- 브라우저 정책상 페이지를 연 뒤 화면을 한 번 눌러야 소리가 납니다.
- 진행 중에 간격을 바꾸면 다음 레벨부터 적용됩니다. 블라인드 값은 바로 반영됩니다.
