# 포커 칩 계산기

맨 위 탭으로 바꿔 씁니다.

- **인원**: 함께 하는 사람 명단. 캐시 게임과 토너먼트가 이 명단을 같이 씁니다.
- **캐시 게임**: 바이인을 기록하고, 게임이 끝나면 남은 칩으로 누가 누구에게 얼마를 보내야 하는지 계산합니다.
- **토너먼트**: 블라인드 타이머, 참가자 바이인·탈락 기록, 등수별 상금과 송금 목록.
- **GTO**: 인원·포지션별 프리플랍 오픈 레인지 차트.
- **확률**: 내 카드, 보드, (알면) 상대 카드를 넣으면 내가 이길 확률과 족보 완성 확률을 계산합니다.

탭마다 포인트 색이 다릅니다: 인원 초록 · 캐시 게임 빨강 · 토너먼트 보라 · GTO 파랑 · 확률 청록.

**바로 쓰기:** https://pigfactory.github.io/poker-chip-calculator/

입력한 내용은 브라우저에 저장되어 새로고침해도 유지됩니다.

## 인원

- 이름을 추가·수정·삭제합니다. 여기서 바꾼 이름이 캐시 게임과 토너먼트에 같이 반영됩니다.
- 어느 한쪽에만 안 하는 사람은 그 모드에서 바이인을 0으로 두면 빠집니다.
- 사람을 지우면 그 사람의 캐시 게임·토너먼트 기록도 같이 지워집니다.

## 캐시 게임 사용법

1. 1바이인 금액과 1바이인 칩 수를 입력합니다 (예: 5,000원 / 500칩).
2. 바이인할 때마다 `+`, 잘못 눌렀으면 `−`. 0이면 불참으로 정산에서 빠집니다.
3. **게임 종료**를 누르고 각자 남은 칩을 입력하면 정산 결과가 나옵니다.
4. **결과 복사**로 카톡 등에 붙여넣을 수 있습니다.

## 정산 규칙

- 송금 건수가 최소가 되도록 잃은 사람 → 딴 사람으로 짝지어 줍니다.
- 남은 칩 합계가 산 칩 합계와 다르면 가장 많이 딴 사람의 칩으로 차이를 맞춥니다.
  - 칩이 남으면 가장 많이 딴 사람 칩에서 뺍니다 (딴 만큼까지만, 넘치면 다음으로 많이 딴 사람).
  - 칩이 모자라면 가장 많이 딴 사람 칩에 더합니다.
  - 어떻게 보정했는지 결과 화면에 설명이 표시됩니다.

## 토너먼트 사용법

토너먼트 안에서 **타이머 / 참가자·상금** 화면을 오갑니다.

### 타이머

1. 시작 스몰·빅과 블라인드 업 간격(분)을 입력하고, 증가 방식을 고릅니다.
   - **같은 값 더하기**: 레벨마다 스몰·빅 증가값만큼 더합니다.
     예: 5/10 시작, +5/+10 → 5/10 → 10/20 → 15/30 …
   - **배수로 올리기**: 레벨마다 ×1.25(느리게) / ×1.33(보통) / ×1.5(빠르게) / ×2(터보)로 올립니다.
     실제 대회 구조표처럼 깔끔한 값(25·50·75·100·125·150·200…)으로 맞추고, 칩 단위(시작 스몰·빅의 최대공약수)로 나눠떨어지는 값만 씁니다.
     예: 25/50 시작, ×1.33 → 25/50 → 50/100 → 75/150 → 100/200 → 125/250 → 150/300 → 200/400 …
2. **미리 알림**에 몇 초 전에 알려줄지 입력합니다 (0이면 끔).
3. **시작**을 누릅니다. 아래 블라인드 스트럭처에서 앞으로 8레벨을 미리 볼 수 있습니다.
4. 남은 인원과 평균 스택(몇 BB인지)이 시계 아래에 나옵니다.

알림

- 미리 알림: 짧은 비프 두 번 + "30초 후에 블라인드가 올라갑니다. 다음은 스몰 10, 빅 20."
- 블라인드 업: 차임 + "블라인드가 올라갑니다. 레벨 2, 스몰 10, 빅 20." 화면도 깜빡입니다.
- 음성은 **음성 안내**로 끌 수 있고, **소리 테스트**로 볼륨을 미리 확인할 수 있습니다.

참고

- 타이머가 도는 동안 화면이 꺼지지 않게 유지합니다 (지원 브라우저).
- 새로고침하거나 화면이 꺼졌다 켜져도 시간이 맞게 이어집니다. 그 사이 지난 레벨은 한 번에 따라잡습니다.
- 브라우저 정책상 페이지를 연 뒤 화면을 한 번 눌러야 소리가 납니다.
- 진행 중에 간격을 바꾸면 다음 레벨부터 적용됩니다. 블라인드 값은 바로 반영됩니다.

### 참가자·상금

1. 1바이인 금액, 1바이인 칩 수, 1인 최대 바이인 수(0이면 제한 없음)를 입력합니다.
2. 모두 1바이인으로 시작합니다. 칩을 다 잃고 다시 사면 `+` (최대 바이인까지), 더 안 사고 나가면 **탈락**.
   - 탈락 순서대로 등수가 매겨지고, 한 명만 남으면 우승입니다. 잘못 눌렀으면 **취소**.
3. 상금은 모든 바이인 금액을 합친 돈입니다. **몇 등까지** 줄지 정하면 기본 비율이 채워지고, 등수별 %를 고칠 수 있습니다 (합계 100%).
   - 기본 비율: 1등 100 / 2등까지 65·35 / 3등까지 50·30·20 / 4등까지 45·27·17·11 / 5등까지 40·25·16·11·8
   - 1,000원 단위로 맞추고 반올림해서 남는 돈은 1등에게 갑니다.
4. 우승자가 나오면 송금 목록(누가 누구에게 얼마)과 개인별 손익이 나오고, **결과 복사**로 붙여넣을 수 있습니다.

## GTO

- 인원(2~9명)과 내 포지션을 고르면, 앞사람이 모두 폴드했을 때 먼저 레이즈할 핸드를 13×13 표로 보여줍니다.
- 표에서 핸드를 누르면 포지션마다 레이즈/폴드를 한눈에 볼 수 있습니다.
- 100BB · 레이크 없음 · 2~2.5BB 오픈 기준으로 솔버 결과를 단순화한 참고용 차트입니다. 섞어서 하는 핸드는 더 자주 하는 쪽으로 정리했습니다.

## 확률

1. 인원과 내 포지션(GTO 탭과 공유), **끝까지 가는 상대** 수를 고릅니다.
2. 칸을 고르고 카드를 눌러 내 카드 2장, 보드(0·3·4·5장), 상대 카드를 넣습니다.
   - 상대 카드는 알면 넣고 모르면 비워 둡니다. 비운 칸은 무작위로 계산합니다.
   - 채운 칸을 다시 누르면 지워집니다.
3. 나오는 값
   - **내가 이길 확률**: 이길·비길·질 확률과 플레이어별 이길 확률.
     - 상대 카드를 다 알면 남은 보드를 전부 세어 본 정확한 값, 모르는 카드가 있으면 2만 번 안팎으로 돌려 본 근삿값입니다.
       (프리플랍은 경우의 수가 너무 많아 상대 카드를 알아도 시뮬레이션)
     - 턴까지 깔렸고 상대 카드를 다 알면, 리버에 나오면 이기는 카드·지는 카드를 보여줍니다.
   - **리버까지 족보 확률**: 최종 족보가 각 등급이 될 확률. 경우의 수가 적으면(플랍·턴) 전부 센 정확한 값입니다.
   - 프리플랍이면 지금 포지션에서 이 핸드를 GTO로 오픈하는지도 알려줍니다.
4. 예: A♠A♥ vs K♣K♦ 프리플랍 → 이김 약 81% · 비김 0.4% · 짐 18.6% (정확한 값 81.06% / 0.38% / 18.55%).
